# Geist

`geist-latin.woff2` is the unmodified Geist 1.401 Latin variable font (weights 100–900), copied from the Next.js dependency's `dist/next-devtools/server/font/geist-latin.woff2`.

Geist is provided by The Geist Project Authors under the SIL Open Font License 1.1. The complete notice and license are included in `OFL-Geist.txt`.

- Project: https://github.com/vercel/geist-font
- License source: https://github.com/vercel/geist-font/blob/main/OFL.txt

The font is checked into this project and loaded through `next/font/local`. Builds and visitors do not need to contact a font provider.
